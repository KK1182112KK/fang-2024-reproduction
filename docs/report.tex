\section{Verification and limits}

These passes do not certify the old stronger claims. Source head was \texttt{4823db9}; source hashes and execution evidence are retained.

Euler steps and nearest-grid lookup remain approximations. No quantitative match to all eight figures, exponential-stability proof, certified mismatch range, MATLAB execution or access to the authors' code is claimed. A small finite-time residual is not an asymptotic theorem. This replaces the earlier unchecked narrative while separating original theory and reproduction work.
